## 2. 关键决策

| 决策 | 原因 |
| --- | --- |
| 三级授权模型 L1/L2/L3 | 区分可入库、仅展示、禁用来源，满足合规 |
| L2 实时层不落库 | 高德协议禁止存储；接口返回 `stored:false` |
| 完整度排序 + 品牌轮转 | 默认首屏展示信息最全的点位，避免单一品牌霸屏 |
| 演示属性清理 | 早期种子用哈希生成价格/年份，必须清除并在前端防御 |
| 服务类型按证据提取 | 只在官网文本出现"对公/对私"时写入，否则"未提供" |
| Pages 静态快照 | 让评委无需后端即可看到全量真实数据（只读） |
| 内部协作文档移出仓库 | AGENTS/MEMORY/COLLAB/skills 不属于交付源码 |
