# 2 在线运行

**GitHub Codespaces**：仓库页 `Code → Codespaces → Create codespace on main`，首次启动自动拉起 MySQL + 后端 + 前端（约 5–10 分钟），端口 8081 为系统首页、18080 为 API、8443 为 HTTPS。

**GitHub Pages**：构建时注入演示数据，只读展示全量真实数据（1,506 网点 / 368 ATM / 3,569 小区），无后端依赖。

**本地 Docker**：

```bash
cp .env.example .env    # 填 DB_PASSWORD / AUTH_SECRET / OPERATOR_PASSWORD
docker compose --env-file .env up -d --build
# 打开 http://127.0.0.1:8081
```

# 3 AI 服务使用

按赛题要求（4. AI 服务使用）说明所用服务、调用方式与集成位置。

## 3.1 所用服务

表 1 AI 服务清单

| 服务 | 模型 / 接口 | 用途 | 是否必需 |
| --- | --- | --- | --- |
| DeepSeek 大模型 | `deepseek-flash`，`POST /chat/completions` | 从搜索结果中结构化抽取营业时间、电话、地址等字段 | 可选，未配 Key 时功能自动关闭 |
| DeepSeek 平台搜索 | `POST /v1/tools/search` | 为抽取提供候选网页与摘要 | 与上者绑定 |
| 高德开放平台 | 逆地理编码、周边搜索、周边设施 | 实时地址与 ATM 补充，仅展示不落库 | 可选，属 L2 通道 |

未使用 OCR、语音识别或第三方 NLP 服务；文本清洗、地址归一、品牌归一等均为本地规则实现。

## 3.2 调用方式

- **协议**：HTTPS + JSON，OpenAI 兼容格式；请求头 `Authorization: Bearer <DEEPSEEK_API_KEY>`。
- **抽取参数**：`response_format = {"type":"json_object"}` 强制 JSON 输出；`thinking = {"type":"disabled"}` 关闭思考模式；单次 `max_tokens` 按字段类型 200–800；超时 90 秒。
- **搜索参数**：`query`、`count`、`need_content = true`，超时 45 秒。
- **密钥管理**：`DEEPSEEK_API_KEY` 由环境变量注入，不入库、不进日志；未配置时 `/api/v1/admin/agent/status` 返回 `enabled=false`，前端隐藏生成入口。
- **失败处理**：非 200 直接抛出并截断响应体前 160 字，失败原因写入 `agent_run.error`；同实体同字段 10 分钟内重复请求返回 busy，`propose` 调用间隔不小于 1.2 秒。

## 3.3 集成位置

表 2 代码集成点

| 位置 | 文件 | 职责 |
| --- | --- | --- |
| 模型客户端 | `backend/.../agent/DeepSeekClient.java` | 封装 `/chat/completions` 与 `/v1/tools/search`，记录 token 与耗时 |
| 业务编排 | `backend/.../agent/AgentService.java` | 搜索 → 抽取 → 独立复核 → 规则校验 → 产出建议（不写库） |
| 接口层 | `backend/.../agent/AgentController.java` | `/api/v1/admin/agent/propose`、`/{runId}/apply`、`/runs`、`/batch`、`/status`、`/quality` |
| 定时任务 | `backend/.../agent/ScheduledAgent.java` | 每日 03:30 自动补一批（默认关闭，`AGENT_SCHEDULE_ENABLED` 打开） |
| 运行记录 | 表 `agent_run` | 模型名、prompt/completion token、耗时、结果 JSON、审核人 |
| 前端入口 | `src/views/AdminView.vue`「Agent 建议」标签页 | 生成建议、查看证据与置信度、采纳 |

## 3.4 使用边界（防幻觉）

- **只建议不写库**：模型输出先落 `agent_run`，管理员点「采纳」才写主表，并写 `poi_version` 与 `poi_field_source`（`operator=agent:<审核人>@来源域名`）。
- **来源白名单**：`SourcePolicy` 只放行银行官网、政府开放数据与 OSM 域名，非 L1 来源直接拒绝，不进入复核。
- **证据回源**：不信任模型自报的证据，回到原始搜索结果做 URL 精确匹配 + 文本归一化包含校验，复现失败标记「疑似幻觉」。
- **规则兜底**：抽取出的地址必须包含实体所属行政区；数值字段做范围校验；同名网点不允许跨区张冠李戴。
- **并发保护**：采纳时校验当前值未被他人修改，冲突返回 409。

## 3.5 用量与成本

累计 115 次运行，单次约 2 秒、成本低于 0.01 元；批量接口一次最多 20 条。模型调用不影响主链路：关闭 Key 或超时，只是「Agent 建议」不可用，查询、反馈、采集照常。
