# 3 界面设计

![图 1 地图查询页（ATM 态）：切到 ATM 后显示 368 台自助设备，与网点互斥展示](assets/shot-atm-map.png)

图 1 为地图查询页切到「ATM」时的实际界面（2026-11-22，1280×720 演示环境截图）。顶部导航为「地图 / 列表 / 洞察」，右上角为访客入口；左侧是图层、区域、银行类型、均价、年代五个筛选块；地图上蓝色圆点为 ATM，聚合点按内容着色；右侧结果列表与地图联动，点击条目可打开详情。底部标注 OpenStreetMap 署名。

![图 2 列表查询页：默认按数据完整度排序，共 1,491 家网点](assets/shot-list.png)

图 2 为列表查询页。顶部显示命中总数与排序方式（数据完整度优先），左侧筛选条件与地图页共用一套；卡片展示名称、地址、区域、品牌与营业时间摘要，地址缺失时显示「地址待补充」而不是留空。

![图 3 数据洞察页：四项指标 + 区域分布 + 品牌与均价分布](assets/shot-stats.png)

图 3 为数据洞察页。顶部四个指标卡为银行网点、ATM、住宅小区、覆盖行政区；下方依次是区域分布条形图、品牌 Top8、均价分桶与网格密度，数据全部来自本地库实时统计，随采集更新。

![图 4 管理后台「反馈审核」：待审列表与采纳/驳回操作](assets/shot-admin-review.png)

图 4 为运营后台的反馈审核页。左侧为状态标签（待审核 / 已采纳 / 已驳回 / 待重抓 / 全部），右侧列表展示反馈编号、点位、字段与提交值；每行提供「采纳生效」与「驳回」，采纳后写主表并记录版本。
