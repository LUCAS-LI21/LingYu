# 1 接口清单

# 2 接口详情

公共约定：入参与存储统一 WGS-84，响应中的 `gcjLng/gcjLat` 为服务端换算的 GCJ-02；`/admin/**` 需 `Authorization: Bearer <token>`；错误码 400 参数错、401 未登录、404 不存在、405 方法不允许、409 状态冲突、429 限流。

# 3 其他

- **契约文件**：`docs/api/openapi.yaml` 为机器可读契约，与本文同步维护。
- **鉴权**：HMAC-SHA256 签名 token，默认 12 小时有效；审核人取自 token 主体，不读请求体。
- **限流**：匿名写接口反馈 10 次/分钟、坐标 20 次/分钟，超限 429。
- **L2 通道**：高德接口不落库、不缓存，响应头 `Cache-Control: no-store`，返回体带 `stored:false`；服务端有每日预算与最小间隔闸门。
