## 二、格式说明

- 首页：项目名称（宋体加粗三号居中）、文档名称（宋体加粗四号居中）、队伍人员 / 报名序号（宋体四号居中）。
- 第二页：目录，Word 域（`TOC \o "1-2"`）生成，仅到二级标题；已预置页码，打开时若提示更新域选"是"（数据库设计目录占两页）。
- 正文从第三页开始，页码从 1 起；一级标题宋体小四加粗，二级宋体五号加粗，三级与正文宋体五号，1.5 倍行距。
- 表标题在表上方居中，图标题在图下方居中。

## 四、重建

```bash
# 1) 改内容；改表结构后先重跑数据库设计生成器
python scripts/build-db-doc.py

# 2) 生成 Word（无目录页码版本）
python scripts/build-initial-docs.py

# 3) 转 PDF 取标题页码，再写入目录重建
python scripts/build-initial-docs.py --extract
python scripts/build-initial-docs.py --with-toc

# 4) 提交清单
python scripts/build-submission-list.py
```

代码变更后先跑同步自检，再决定是否重建：

```bash
node scripts/docs-sync-check.mjs   # 硬事实缺失时退出码 1
```
