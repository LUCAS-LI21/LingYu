## 二、格式说明（对照《初赛提交资料要求》）

- 首页：项目名称（宋体加粗三号居中）、文档名称（宋体加粗四号居中）、队伍人员 / 报名序号（宋体四号居中），无其他内容。
- 第二页：目录，按 Word 域（`TOC \o "1-2"`）生成，小四、1.5 倍行距，仅到二级标题；已预置页码，Word 中打开若提示"更新域"选择"是"即可刷新为最新页码。
- 正文从第三页开始，页码从 1 起（分节符 + `pgNumType start=1`）。
- 标题级次：一级宋体小四加粗、二级宋体五号加粗、三级与正文宋体五号，全部 1.5 倍行距。
- 表标题在表上方居中，图标题在图下方居中。

## 四、重新生成

```bash

# 2) 构建 Word（先生成不带目录页码的版本）
python scripts/build_initial_docs.py

# 3) 转 PDF 取标题页码（LibreOffice Kit，见 skill office-export-pdf）
#    再用 --extract 读取页码、--with-toc 写入目录后重建
python scripts/build_initial_docs.py --extract
python scripts/build_initial_docs.py --with-toc

# 4) 提交清单
python scripts/build_submission_list.py
```
