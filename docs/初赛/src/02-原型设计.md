# 2 界面内容

表 2 各界面主要展示内容与功能

| 界面             | 主要展示内容                                                                           | 主要功能                                                                                                                        |
| ---------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 地图查询         | 全屏地图（OSM 底图）、银行/小区标记与聚合点、左侧筛选面板、右侧结果列表、详情侧栏      | 图层切换（银行/小区）、网点/ATM 互斥切换、区域与价格/年代筛选、矩形框选、点击弹窗、周边 1 公里银行、高德/腾讯导航跳转、纠错入口 |
| 列表查询         | 卡片与表格混排结果、筛选栏、排序与分页器、详情抽屉                                     | 关键词搜索、按区/类型/价格/年代筛选、5 种排序、分页、查看详情、提交纠错、查周边                                                 |
| 数据洞察         | 四个指标卡（银行/ATM/小区/覆盖区）、区域分布条形图、品牌 Top8、均价分桶、网格密度 Top6 | 按区与类型筛选、下钻到列表、实时统计（随采集更新）                                                                              |
| 数据说明         | 三级授权模型、数据来源清单、不采集清单、免责声明                                       | 查看来源与许可、了解合规边界                                                                                                    |
| 后台概览         | 待审反馈、任务数（成功/失败）、版本数、平均新鲜度                                      | 快速跳转到待办                                                                                                                  |
| 反馈审核         | 待审列表、字段差异、审核人、审核意见                                                   | 采纳生效、驳回、查看关联版本                                                                                                    |
| Agent 建议       | AI 抽取结果、证据与来源 URL、置信度                                                    | 采纳写库、批量生成建议、查看运行记录                                                                                            |
| 查询行为         | 查询日志、热点网格与优先级                                                             | 重算热点、按优先级查看区域                                                                                                      |
| 数据纠错         | 反馈类型与状态分布                                                                     | 按类型筛选、定位问题点位                                                                                                        |
| 抓取任务         | 任务列表（触发方式/状态/抓取/新增/更新/错误）                                          | 手动触发抓取、查看失败原因                                                                                                      |
| 存量用地         | 宗地表、四个指标卡（总数/当前列表/合计面积/住房类型数）                                | 按区筛选、查看宗地详情                                                                                                          |
| 待定位小区       | 4,940 条名录、待审坐标列表、地图标注弹窗                                               | 区筛选、关键词搜索、地图点选坐标、转正、审核用户提交的坐标                                                                      |
| 待定位网点       | 50 条暂存网点、来源与地址                                                              | 标注位置并转正、刷新                                                                                                            |
| 数据说明（后台） | 数据源注册表、存储策略、许可                                                           | 查看数据源与合规信息                                                                                                            |

# 3 界面设计

![图 1 地图查询页：部署环境实际运行截图，当前命中 1,528 个银行网点](assets/shot-map.png)

图 1 为 Docker 部署环境的地图查询页（`https://127.0.0.1:8443/`，2026-11-18 验收截图）。左侧为图层与筛选面板，中间为 Leaflet 地图与聚合标记，右侧为联动结果列表；顶部为全局导航，右上角常驻「数据合规」入口。地图交互包括缩放、平移、矩形框选、点击弹窗，底部标注 OpenStreetMap 署名。

![图 2 管理后台「待定位网点」：50 条只有地址没有坐标的网点，标注后转正](assets/shot-admin-pending.png)

图 2 为运营后台的待定位网点页。每行展示网点名称、地址、电话、来源与「标注位置并转正」按钮；顶部说明"有名称地址、缺坐标的银行网点（官网来源 + 用户反馈新增），标注位置后转正进地图"。这一页把"抓不到坐标就不伪造"的原则落到了界面上。

![图 3 后端停机时的离线降级：顶部横幅提示，地图回落内置示例数据](assets/shot-offline.png)

图 3 为后端不可达时的降级效果：顶部出现黄色横幅"后端未连接：当前展示的是内置示例数据（约 339 条，非全量）"，地图与列表仍可用。该设计用于演示现场网络异常时保底。
