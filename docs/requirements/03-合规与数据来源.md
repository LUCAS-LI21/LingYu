# 数据采集合规说明（硬约束）v0.2

> 赛题原文：「数据抓取不能违法」。本文把"能不能抓"落成**三级授权模型 + 实测证据**，每次采集都要过这张表。
> v0.2 更正：上一版把"官方 API"一律标为 A 级推荐，这是错的——**高德/百度 API 允许展示，但不允许存储**。详见 §1。

## 1. 核心结论：可以"看"，不可以"存"

| 用法                                           | 可行性                  | 依据                                                                         |
| ---------------------------------------------- | ----------------------- | ---------------------------------------------------------------------------- |
| 调用地图开放平台 API，在应用里**即时展示**结果 | ✅ 可以                 | 高德服务协议 3.5：允许"对相关服务数据的结果进行展示"                         |
| 调用 API 把结果**存进自己的数据库**            | ❌ 不可以（需单独授权） | 高德服务协议 3.5：**"不得直接存储、缓存或技术手段抓取、使用本服务内部数据"** |
| 抓取 robots **允许**的公开网页                 | ⚠️ 视站点               | 需逐一实测 robots + 阅读该站条款                                             |
| 抓取 robots **禁止** / 需登录 / 有验证码的站   | ❌ 不可以               | 见 §2 实测                                                                   |

**一句话**：地图 API 的数据能"即取即显"，不能"落库成自己的数据资产"；网页能抓的只有明确不拒绝你的那些站。

## 2. 实测证据（2026-11-05，主代理亲自核验）

| 目标                                              | 实测结果                                                                                                     | 结论                                            |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------- |
| 高德开放平台服务协议（页面标注更新于 2025-12-03） | 3.5 条：不得直接存储/缓存/抓取本服务内部数据；3.4 条：不得用于模型或算法训练；4.6 条：交互产生数据归高德所有 | API 数据**只能即取即显**，不能入库              |
| `lianjia.com/robots.txt`                          | `User-agent: *` → `Disallow : /*`                                                                            | **全站禁止**任何爬虫                            |
| `ke.com/robots.txt`                               | 同上                                                                                                         | **全站禁止**                                    |
| `anjuke.com/robots.txt`                           | `User-agent: *` → `Allow: /`（同时显式 Disallow ClaudeBot、GPTBot、okhttp 等）                               | 允许访问，但站点条款与反不正当竞争风险仍在      |
| `icbc.com.cn/robots.txt`                          | HTTP 404（无 robots 文件）                                                                                   | 未声明禁止，可低频访问（仍受限速与条款约束）    |
| OSM Overpass API（深圳福田+罗湖 78 km² 实测）     | 银行/ATM 节点 **182** 个、`landuse=residential` 面 **792** 个；响应含 ODbL 声明；未带 UA 时被 406 拒绝       | ✅ **覆盖可用**，单次 32–41s，须离线批量 + 缓存 |

> 注意：`anjuke.com` 的 `Allow: /` 只说明"不拒绝通用爬虫"，不等于"授权你建立数据库并对外提供查询"。**robots 允许 ≠ 商业使用许可**。

## 3. 三级授权模型（落到 `ds_source` 表）

| 级别          | 定义                                                    | 允许的操作                           | 本项目例子                                                 |
| ------------- | ------------------------------------------------------- | ------------------------------------ | ---------------------------------------------------------- |
| **L1 可入库** | 许可明确允许存储、加工、再分发（可能有署名/同许可义务） | 采集 → 清洗 → 入库 → 展示 → 版本管理 | OSM/Overpass（ODbL）、政府开放数据、自建种子数据、用户反馈 |
| **L2 仅展示** | 只允许调用后即时展示，**不得存储**                      | 实时透传展示、不落库、不缓存         | 高德/百度开放平台 API                                      |
| **L3 禁用**   | robots 禁止、需登录、有验证码、或条款明确禁止           | 不访问                               | 链家、贝壳（实测 Disallow）                                |

技术落点：`ds_source.storage_policy` 字段取 `storable` / `display_only` / `forbidden`。
**采集服务在写库前必须校验**：来源是 `display_only` 却要写库 → 直接抛 `ComplianceException`，任务标记 rejected。

## 4. 本项目的数据源策略（深圳）

### 4.1 主库（L1，可入库）

| 来源                       | 提供字段                                                                                                                                            | 状态             |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| OSM / Overpass API（ODbL） | 银行网点（`amenity=bank`）、ATM（`amenity=atm`）、小区（`landuse=residential` / `place=neighbourhood`）、名称、地址、坐标、`phone`、`opening_hours` | 覆盖度待实测     |
| 深圳市/区开放数据平台      | 公共机构、学校、医院、公园等 POI；行政区划                                                                                                          | 待核实具体数据集 |
| 自建种子数据               | 小区均价/建成年份/物业费等商业属性（标注"演示数据"）                                                                                                | ✅ 可控          |
| 用户反馈                   | 纠错与补充（标注"用户提供·待核实"）                                                                                                                 | ✅ 闭环核心      |

### 4.2 实时增强（L2，不落库）

高德 Web 服务 API（`/v3/place/around`）：用户在地图上查看某点时，**即时**返回周边结果并展示，页面标注"实时数据来自高德，未存储"。不写库、不缓存、不导出。

### 4.3 明确不碰（L3）

链家、贝壳及任何 robots 全站禁止的房产站；任何需登录/验证码/付费墙的页面。

## 5. 采集前检查清单

- [ ] 目标域名在 `ds_source` 白名单内，`enabled=true`
- [ ] **`storage_policy` 与本次操作匹配**：要入库的必须是 `storable`
- [ ] L2 来源确认"只展示、不写库、不缓存"
- [ ] 网页类：`/robots.txt` 已拉取并缓存（≤ 24h），目标路径未被 `Disallow`
- [ ] 请求频率 ≤ 配置值（默认 1 QPS），并发 ≤ 1
- [ ] User-Agent 标明项目与联系方式
- [ ] 不采集任何个人信息（个人手机号正则拦截）
- [ ] 原始响应按保留期存储且不对外分发（仅 L1 来源可存）

## 6. 技术实现要求

| 要求         | 实现方式                                                                  |
| ------------ | ------------------------------------------------------------------------- |
| 速率限制     | 令牌桶，每数据源独立；默认 1 QPS                                          |
| 退避重试     | 指数退避 + 抖动；429/5xx 最多 3 次                                        |
| robots 校验  | `RobotsGuard`：抓取前检查并缓存（≤24h），不允许则抛 `ComplianceException` |
| 存储策略校验 | `StoragePolicyGuard`：`display_only` 来源禁止写库                         |
| 白名单       | 域名 + 路径前缀，配置化，运行时不可被接口篡改                             |
| 紧急开关     | `crawler.enabled=false` 一键停采                                          |
| 审计         | 每次外部请求写 `ingest_log`（URL 脱敏、状态码、耗时、robots 结果）        |
| 密钥管理     | Key 存环境变量/加密字段，不进日志、不进 Git                               |

## 7. 法律边界

- 《网络安全法》：不得非法侵入、干扰他人网络正常功能。
- 《数据安全法》：数据分类分级，不得违规获取、交易数据。
- 《个人信息保护法》：**不采集个人信息**；商家公开电话属经营信息，个人手机号一律不采。
- 《反不正当竞争法》第十二条：不得以技术手段妨碍、破坏他人合法提供的网络产品或服务正常运行；"实质性替代"（整体搬运他人数据库）风险最高。
- **robots 协议**：不是法律，但是判断"是否获得访问许可"的关键事实依据。
- 违约与违法的区别：违反平台 ToS 通常是**民事违约**，不等于行政或刑事违法；但对比赛而言，"赛题要求合法"这条已经过不去了，所以按 L1/L2 分治。

## 9. 演示话术（1 分钟，比上一版更硬）

> "我们没有用高德的数据建库。高德服务协议 3.5 条明确禁止存储 API 返回的数据，所以高德只做实时展示、不落库。入库的数据全部来自可存储的开放数据：OSM（ODbL 许可）、政府开放数据和我们自建的种子数据；小区均价这类商业属性没有合法公开来源，我们标成'演示数据'并由用户反馈补全。每次采集都过白名单、robots 和存储策略三道校验，有审计日志和紧急停采开关。"

这段话的价值：**主动指出合规红线并给出解法**，比"我们抓了很多数据"更能得分。

## 10. 红线

| 行为                | 判定         | 处理                               |
| ------------------- | ------------ | ---------------------------------- |
| 把高德 API 结果落库 | 违反 ToS 3.5 | 代码层拦截（`StoragePolicyGuard`） |
| 抓链家/贝壳         | 违反 robots  | 白名单外，直接拒绝                 |
| 绕过验证码/登录     | 违法风险     | 代码不提供该能力                   |
| 采集个人手机号      | 违反 PIPL    | 正则拦截 + 字段级过滤              |
| 分发原始数据包      | 违反 ToS     | 不提供导出能力                     |
| 未标注来源          | 违反 ToS     | 详情页固定展示来源与许可           |
