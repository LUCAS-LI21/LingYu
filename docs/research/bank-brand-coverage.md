# 深圳银行品牌覆盖分析（2026-11-10）

> 目的：回答"我们缺哪些银行、缺多少"，据此决定先做哪几家的官网适配器。
> 数据来源：国家金融监督管理总局许可证库（样本）+ 本地 OSM 库。

## 方法

1. 从许可证库按「机构地址含深圳」查询，共 **1989** 条（页面口径，2026-11-09 更新）。
2. 因服务端深分页限制（约 250 条后返回空），实际抓到 **750 条样本**（按发证日期排序）。
3. 按品牌聚合样本，再按 `1989 / 750` 等比放大，得到"估算全量"。
4. 与本地 `poi_bank`（343 条，其中 321 条有品牌）逐品牌比对。

**局限**：样本按日期排序，不代表随机抽样，估算值有误差；仅用于排序，不作为精确统计。

## 结论

1. **整体覆盖 17%**，缺口集中在 5 家：建行、招行、兴业、邮储、广发，
   合计约 **850 家**，占全部缺口的 **≈ 50%**。
2. 工行、中行覆盖已过半（56%、63%），**不必再花力气**。
3. 有 13 个品牌我们**一家都没有**（华润、深通村镇、浙商、桂银村镇…），
   多为城商行/村镇银行，网点少但集中，适合批量补。

## 与 Agent 的关系

上一轮实测：泛名点位（"交通银行"）Agent 无法确认身份，全部转人工；
带网点级别的名称（"汇丰银行深圳湾支行"）3/3 自动通过。

**所以顺序是**：先通过官网爬取拿到"支行名 + 地址 + 坐标" → 库里名称变细 →
Agent 才能对泛名点位做自动补全。反过来会白跑。
