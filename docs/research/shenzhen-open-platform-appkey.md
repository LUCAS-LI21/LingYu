# 深圳市政府数据开放平台 appKey 申请入口核查

- 核查时间：2026-11-10
- 站点：https://opendata.sz.gov.cn/
- 方法：直接 HTTP 抓取（未登录态）+ 官方 PDF 文档抽取，全部结论附可打开证据

## 一、结论（为什么用户找不到）

appKey 的申请入口**不在**「应用 → 开发者中心」首页（该页 `appKey` 出现 0 次），
而在它的二级页 **「应用成果提交」**；appKey 的查看位置**也不在**开发者中心，而在
**「个人中心 → 应用成果」**。官方《API 调用操作指南》原文：

> 1. 调用 API 需在首页通过【应用】—【开发者中心】进入开发者中心菜单。
> 2. 进入开发者中心后点击【应用成果提交】即可进入相应页面申请 API 调用所需的 AppKey。
> 3. 平台提供多种申请 Appkey 的方式如"移动 app"、"微信小程序"、"web 应用"、"研究报告"。
> 4. 提交相应应用成果后，点击【个人中心】—【应用成果】，即可查看申请应用成果对应的 Appkey。
> 5. 调用 API 前，需先订阅对应的数据接口……选择已提交的应用，完成数据接口订阅。

来源：<https://opendata.sz.gov.cn/downloadFiles/open-file/Api接口调用操作指南.pdf>
（已核实：HTTP 200，3,488,895 bytes，7 页）

## 三、需登录后可见（推断部分）

未登录访问个人中心子页时，服务端返回**首页 HTML**（200，264,692 bytes），而非 404。
对照组：不存在的路径返回 404（1,650 bytes 的 404 页）。据此判定为鉴权拦截。

- 已核实存在的子页：`/maintenance/personal/toApiTest`（接口测试）、
  `/maintenance/personal/toSubscribe`（我的订阅）、`/maintenance/personal/toUserInformation`（账号信息）
- **未取得**「应用成果」页 URL；按官方 PDF 菜单名，登录后路径为
  `个人中心 → 应用成果`（菜单文字来自 PDF p2，页内 URL 为推断，未核实）

## 四、其他坑

- 线索中的 `api/1514671018/1/service.xhtml` 路由有效（返回 10009 而非 404），
  但 `1514671018` 属旧式数字 id；现行 `api_context` 形如 `api/29200_00903509/1/service.xhtml`。
- `/data/api/toApiDetails/1514671018` 直接 404——详情页要用 `29200_00903509` 这类 resId。
- 接口详情页存在被注释掉的历史逻辑「非疫情数据适用 100 条登陆限制，现规则先注释掉」，
  与接口配额无关，勿误读为调用上限。
