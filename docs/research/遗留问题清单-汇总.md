## 补充：全网检索新增的两个数据源（2026-11-16 下午）

用户质疑"是否真的搜过"，遂重新检索，找到两条此前遗漏的线索：

### A. 深圳市「小区租赁参考价格」（29200/01903546，4 319 条，无条件开放）⭐

**这是目前唯一同时带地址与坐标的官方小区级数据**：

| 字段                            | 说明                                                  |
| ------------------------------- | ----------------------------------------------------- |
| PARK_NAME                       | 小区名称                                              |
| QU_NAME / STREET / ADDRESS      | 行政区 / 街道 / 地址                                  |
| DC_PRICE / GC_PRICE / DMD_PRICE | 多层 / 高层 / 低密度租金（元/㎡·月）                  |
| GEOM                            | 地理坐标（**2000 国家大地坐标系**，与 WGS-84 差 <1m） |

价值：能给小区补**真实租金**、补**缺失地址**、补**缺失坐标**（政府数据可合法存储）。
**状态：接口需订阅（10001）**，脚本已写好：`scripts/import-rent-reference.mjs`，订阅后一条命令即可导入。
订阅页：https://opendata.sz.gov.cn/data/api/toApiDetails/29200_01903546

### B. Kaggle「中国主要城市二手房真实挂牌数据」（170MB，标注 MIT）⚠️

- 含城市/小区/面积/户型/**楼龄**/价格/关注数/带看量
- 许可证填 MIT，但数据来自商业平台挂牌信息，上传者未必有权再分发 → **provenance 存疑**
- 结论：可作为"如果一定要真实均价"的备选，但需在答辩中说明来源与风险；优先用 A

### 仍不存在的

- 官方**小区级成交均价**：全市仅 463 条（罗湖），归一化匹配后仅对上 23 个小区（5%）
- 官方**小区级建成年份**：无任何数据集提供
