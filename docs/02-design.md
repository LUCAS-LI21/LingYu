# ② 设计

> 目标：把「好看」变成**可复用的令牌与组件语义**，让实现阶段不再靠感觉调样式。

## 用到的工具

| 工具                      | 作用                  | 为什么选它                                                             |
| ------------------------- | --------------------- | ---------------------------------------------------------------------- |
| Tailwind CSS v4           | 原子化样式 + 设计令牌 | 使用量最大的 CSS 框架；v4 用 CSS-first 配置，无需 `tailwind.config.js` |
| Element Plus              | 中后台组件库          | Vue 生态最常用的 UI 库，表单/表格/反馈组件齐全                         |
| Iconify（unplugin-icons） | 图标按需引入          | 20 万+ 图标，编译期转成 Vue 组件，不额外发请求                         |

## 设计令牌

令牌集中在 `src/assets/main.css` 的 `@theme` 中，只改一处即可全局换色：

```css
@theme {
  --color-brand-500: #42b883;
  --color-brand-600: #369d6f;
}
```

使用时直接 `bg-brand-500`、`text-brand-600`，不再写魔法色值。

## 组件分层

| 层       | 位置              | 规则                          |
| -------- | ----------------- | ----------------------------- |
| 基础组件 | `src/components/` | 只受 props 驱动，不带业务请求 |
| 业务组件 | `src/views/` 内   | 可连 store、可发请求          |
| 布局     | `src/App.vue`     | 只负责壳与导航                |

## 验收清单

- [ ] 颜色/圆角/间距全部走令牌，无散落十六进制值
- [ ] 移动端（375px）与桌面端（1440px）两档都过一遍
- [ ] 交互态齐全：hover / focus / disabled / loading / empty
- [ ] 组件 props 有类型，禁止 `any` 传参
