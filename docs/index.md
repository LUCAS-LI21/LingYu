# 邻域 POI 情报系统

> 银行网点与小区信息的采集、清洗、多维查询与**数据持续更新闭环**。

## 这个项目解决什么

办业务、选住处时，银行网点和小区信息散落在高德、房产网站、银行官网。本项目把它们归一到一个系统里：**采得到、洗得净、查得快、错了能改、改了能自动更新**。

## 三条闭环（核心卖点）

```text
A 纠错闭环：用户反馈 → 审核 → 版本落库 → 地图/列表立即更新 → 状态回流用户
B 补采闭环：查询为空 → 请求补充 → 定向抓取任务 → 新点位入库 → 再查询可见
C 热点闭环：查询日志 → 每日聚合热点 → 调度器优先抓热点区 → 数据更新 → 体验提升
```
