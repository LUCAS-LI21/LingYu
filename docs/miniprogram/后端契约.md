# 小程序端后端契约

> 小程序与 Web 共用同一个 Spring Boot 后端（默认 `http://127.0.0.1:8080`，生产换成 HTTPS 域名）。
> 本文只写小程序接入必需的信息；字段全量定义见 [数据字典](../requirements/02-数据字典.md)。

## 1. 通用约定

| 项       | 约定                                                               |
| -------- | ------------------------------------------------------------------ |
| 响应信封 | `{ "code": 0, "message": "ok", "data": ... }`，`code !== 0` 即失败 |
| 鉴权     | 运营接口用 `Authorization: Bearer <token>`；公开查询接口无需 token |
| 时间     | ISO-8601 字符串（`2026-11-15T21:56:13`）                           |
| 分页     | `page`（1 起）+ `size`（服务端上限见各接口）                       |
| 编码     | UTF-8；中文直接返回，不需要额外转码                                |

### 小程序侧必须注意

1. **域名白名单**：小程序只能请求已在小程序后台配置的 `request` 合法域名，且必须是 **HTTPS**。
   开发期可在「详情 → 本地设置」勾选"不校验合法域名"，但上线前必须配好。
2. **不要带 Cookie**：后端用 Bearer token，不用 session，小程序也不需要 `withCredentials`。
3. **CORS 与小程序无关**：`wx.request` 不受同源策略限制；CORS 只影响浏览器（Web 端已处理）。
4. **坐标系**：见第 3 节，务必用 `gcjLng / gcjLat` 做地图展示与导航。

## 2. 核心接口

### 2.1 列表查询（地图/列表页）

```
GET /api/v1/pois?types=bank,community&district=福田区&keyword=招商&page=1&size=20
```

| 参数                                      | 说明                                                                  |
| ----------------------------------------- | --------------------------------------------------------------------- |
| `types`                                   | **复数**，逗号分隔：`bank` / `community`；不传等于全部                |
| `keyword`                                 | 名称/地址模糊匹配                                                     |
| `district`                                | 行政区名（`福田区`…）                                                 |
| `branchType`                              | `all` / `branch`（网点）/ `atm`                                       |
| `minPrice` `maxPrice` `minYear` `maxYear` | 小区均价/年份筛选                                                     |
| `west` `east` `south` `north`             | 地图视野内筛选（传了只返回视野内点位）                                |
| `sort`                                    | `default` / `priceAsc` / `priceDesc` / `yearAsc` / `yearDesc`         |
| `page` `size`                             | 分页，`size` 上限 20000（首屏一次拉全量用 20000，配合 gzip 约 286KB） |

返回：`{ items: Poi[], total, page, size }`

### 2.2 详情

```
GET /api/v1/pois/{id}
```

返回单个 `Poi`（银行与小区同构，用 `type` 区分）。小区额外字段：

`builtYear` `avgPrice` `propertyFee` `propertyCompany` `waterSavingYear`
`surroundBankCount` `surroundAtmCount` `nearbyBrandCount` `nearestBankM`

### 2.3 周边银行（按半径）

```
GET /api/v1/pois/nearby?lng=114.06&lat=22.54&radius=1000&branchType=all&limit=100
```

> 入参 `lng/lat` 用 **WGS-84**（与库里一致），服务端内部算球面距离。

### 2.4 最近 N 家银行（详情页用）

```
GET /api/v1/pois/{id}/nearest-banks?limit=3&radius=5000
→ { poiId, items: [{ id, name, brand, address, branchType, distance }] }
```

`distance` 单位米，直线距离（非步行路径）。

### 2.5 字段级来源

```
GET /api/v1/pois/{id}/sources
→ [{ field, source, source_url, updated_at }]
```

用于详情页「数据来源」区块，回答"这条地址哪来的"。

### 2.6 统计（洞察页）

```
GET /api/v1/stats
→ { total, bank, atm, branch, community, districts, brands[], byDistrict[], priceBuckets[], gridTop[] }
```

`byDistrict` 形如 `[{ label: "福田区", bank: 360, community: 754 }]`；JDBC 的 `SUM()` 返回字符串，**前端要 `Number()` 转换**。

### 2.7 待定位小区（有地址、缺坐标）

```
GET /api/v1/community-pending?district=南山区&keyword=花园&page=1&size=20
→ { total, page, size, items: [{ id, name, address, district, street, attribute }] }
```

小程序里可用 `wx.openLocation` 的替代方案：跳转外部地图或显示地址文本（这类点位没有坐标）。

### 2.8 存量住宅用地（宗地级）

```
GET /api/v1/land-parcels?district=南山区&limit=20
→ { total, items: [{ id, district_street, location, area_ha, housing_type, build_status, developer, project_name, supply_date }] }
```

注意：此接口字段是 **snake_case**（直接来自表列名），与其他接口的 camelCase 不同。

### 2.9 反馈与实时层

| 接口                                      | 说明                                                            |
| ----------------------------------------- | --------------------------------------------------------------- |
| `POST /api/v1/feedback`                   | 用户纠错/补充，无需登录                                         |
| `GET /api/v1/live/address?lng=&lat=`      | L2 实时地址（未配 `AMAP_KEY` 时返回 `{enabled:false, reason}`） |
| `GET /api/v1/live/pois?lng=&lat=&radius=` | L2 实时周边，**只展示不落库**                                   |

## 3. 坐标系（最容易踩的坑）

库里存的是 **WGS-84**（`lng` / `lat`），接口额外返回算好的 **GCJ-02**（`gcjLng` / `gcjLat`）：

```json
{ "lng": 113.881756, "lat": 22.582274, "gcjLng": 113.886647, "gcjLat": 22.579233 }
```

| 用途                                    | 用哪套                                |
| --------------------------------------- | ------------------------------------- |
| 球面距离计算、`nearby` 入参             | `lng` / `lat`（WGS-84）               |
| 高德 / 腾讯地图展示、导航               | `gcjLng` / `gcjLat`（GCJ-02）         |
| 小程序 `wx.openLocation` / `<map>` 组件 | `gcjLng` / `gcjLat`（微信要求 gcj02） |

**不要**把 `lng/lat` 直接喂给高德或微信地图，会偏 500 米左右。

### 导航跳转（小程序）

```js
// 微信内置地图打开（推荐，无需 key）
wx.openLocation({
  latitude: poi.gcjLat,
  longitude: poi.gcjLng,
  name: poi.name,
  address: poi.address,
  scale: 18,
})

// 或唤起高德小程序 / 外部 App（用 URI API，注意 lng,lat 顺序）
const url = `https://uri.amap.com/navigation?to=${poi.gcjLng},${poi.gcjLat},${encodeURIComponent(poi.name)}&mode=car&coordinate=gaode&src=poi-intel`
```

腾讯地图 URI 的坐标顺序是 `lat,lng`（与高德相反），详见 `src/lib/nav.ts` 的实现与单测。

## 4. 错误码与限流

| code | 含义                                     | 处理                           |
| ---- | ---------------------------------------- | ------------------------------ |
| 0    | 成功                                     | —                              |
| 400  | 参数错误                                 | 提示用户                       |
| 401  | 未登录/token 失效                        | 重新 `POST /api/v1/auth/login` |
| 404  | 资源不存在                               | 回列表                         |
| 409  | 状态冲突（如建议已过期、字段已有人填写） | 刷新后重试                     |
| 500  | 服务端异常                               | 上报并降级到缓存               |

后端对分页 `size` 有上限（pois 为 20000），超过会被截断到上限，不会报错。

## 5. 鉴权（仅运营功能需要）

```
POST /api/v1/auth/login
{ "username": "operator", "password": "..." }
→ { code: 0, data: { token, username, expiresIn } }
```

后续请求带 `Authorization: Bearer <token>`。token 由 HMAC-SHA256 签发，默认 7 天过期。

## 6. 建议的小程序页面与接口映射

| 页面               | 接口                                                                         |
| ------------------ | ---------------------------------------------------------------------------- |
| 首页地图           | `GET /pois?west&east&south&north&types=`（按视野拉取）                       |
| 列表/搜索          | `GET /pois?keyword=&district=&types=`                                        |
| 详情               | `GET /pois/{id}` + `GET /pois/{id}/nearest-banks` + `GET /pois/{id}/sources` |
| 导航               | `wx.openLocation`（用 `gcjLng/gcjLat`）                                      |
| 纠错提交           | `POST /feedback`                                                             |
| 洞察（可选）       | `GET /stats`                                                                 |
| 待定位小区（可选） | `GET /community-pending`                                                     |

### 2.10 待定位小区：提交坐标（众包）

待定位小区只有名称与地址、没有经纬度。坐标只能靠**用户确认**产生（商业地图坐标禁止落库，见数据源矩阵）。

```
POST /api/v1/community-pending/{id}/locate
Content-Type: application/json

{ "lng": 113.9301, "lat": 22.5331, "note": "小区南门口" }
→ { code: 0, data: { status: "pending", message: "已提交，等待管理员核实" } }
```

- 无需登录；提交后进入 `coordinate_submission` 待审队列
- 管理员通过后写入 `poi_community`（来源「用户贡献」），立即出现在地图与列表
- 坐标必须落在深圳范围内，否则 400

小程序端推荐流程：

```js
wx.getLocation({
  type: 'gcj02',
  success: (res) => {
    // wx 返回 GCJ-02，后端存 WGS-84：先转再提交，或让后端加参数（当前约定 WGS-84）
    // 若不方便转换，可让用户在地图上拖动选点（<map> 组件 binderror 不受影响）
    wx.request({
      url: `${BASE}/api/v1/community-pending/${id}/locate`,
      method: 'POST',
      data: { lng, lat, note: '实地确认' },
    })
  },
})
```

> 坐标系提醒：接口约定入参为 **WGS-84**，而 `wx.getLocation({type:'gcj02'})` 给的是 GCJ-02。
> 两种做法：① 小程序侧用 `gcj02ToWgs84` 转换后再提交；② 接口增加 `coordType=gcj02` 参数由后端转换。
